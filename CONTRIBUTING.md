# Contributing

Branch from `captain/pulsev1d`, push, ask Ry for review in the room.

`git switch -c <you>/<short-title> origin/captain/pulsev1d`, commit, then
`git push -u origin <branch>` and say "pushed `<branch>` for T<n> — <what>,
<how verified>, ready for review".

The contract in README.md is settled — build against it as written; if it's
missing something you need, ask Ry rather than guessing.
